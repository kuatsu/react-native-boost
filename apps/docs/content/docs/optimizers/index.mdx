## Shared component safety rules

When optimizing a component, all optimizers first confirm that the component comes from `react-native`. A component from another package, or a local component with the same name, is not changed.

Boost also skips a component when:

- Its file matches an [`ignores`](/docs/configuration/configure#plugin-options-ignores) pattern.
- Its line has [`@boost-ignore`](/docs/configuration/boost-decorator#boost-ignore).
- Required information is only available at runtime.

Set `logLevel: 'debug'` to see why a component was skipped.

## Literal JSX spreads

On known iOS and Android targets, Text, View, Image, and ActivityIndicator can use direct literal spreads:

```jsx
<View {...{ id: 'card', tabIndex: 0 }}>
  <Text {...{ numberOfLines: 2, style: [{ color: 'red' }, { color: 'blue' }] }}>Label</Text>
  <Image {...{ source: { uri: 'logo.png' } }} />
  <ActivityIndicator {...{ size: 'large' }} />
</View>
```

Boost opens these spreads before the component checks and before React Compiler runs. It keeps the original value expressions and style arrays. Existing component, platform, ancestry, and styling-integration restrictions still apply. Rejected sites, ignored sites, and disabled optimizers keep their spreads.

Only plain, noncomputed data properties with static literal values qualify. Nested literal objects and arrays can qualify too. Boost does not open getters, methods, nested spreads, array holes, `__proto__`, `key`, or `ref`. It rejects duplicate keys within an object and prop collisions across attributes or spreads. It also rejects unknown spreads and impure neighboring prop expressions.

Boost does not evaluate identifier spreads, helper calls, callback functions inside spreads, or arbitrary objects. An Image callback can remain a separate direct attribute if it passes the [callback checks](./native-image#load-callbacks).

## Controlling optimizers

Most optimizers are enabled by default. Exceptions are:

- The [Animated Wrapper Removal optimizer](./animated-wrapper-removal) is enabled by default only for React Native 0.83 through 0.86.

You can turn each optimizer on or off in `metro.config.js`:

```js
module.exports = withBoostConfig(config, {
  optimizations: {
    'native-image': 'off',
    'animated-wrapper-removal': 'on',
  },
});
```

See [Configure Boost](/docs/configuration/configure#optimization-options) for all options.
