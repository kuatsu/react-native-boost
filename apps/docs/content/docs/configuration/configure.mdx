title: Configure the Babel Plugin

The Babel plugin (`react-native-boost/plugin`) is the core of React Native Boost. Its defaults enable all stable optimizations.

## Example Configuration

Only set values that differ from the defaults:

```js
// babel.config.js
module.exports = {
  plugins: [
    [
      'react-native-boost/plugin',
      {
        logLevel: 'debug',
        ignores: ['node_modules/**'],
        integrations: {
          unistyles: 'on',
        },
        optimizations: {
          'native-activity-indicator': 'off',
        },
      },
    ],
  ],
};
```

## Environment-Specific Enablement

You can enable React Native Boost by environment with Babel `env` config:

```js
module.exports = {
  env: {
    development: {
      plugins: ['react-native-boost/plugin'],
    },
  },
};
```

See Babel docs: https://babeljs.io/docs/options#env
